# Интерфейс подбора КТРУ

Интерфейс работает с настоящим RAG API из `src/rag/`. Моковых ответов, искусственных
задержек и резервного демонстрационного каталога нет.

## Запуск

Из корня проекта:

```bash
uv sync
uv run --env-file .env rag-api
```

Нужны индекс `RAG_DATA` и доступ к моделям по корневому README. Если файлы индекса отсутствуют,
API запускается для диагностики, но `/health` и поиск возвращают 503. После установки
индекса перезапустите API. Отсутствие данных не заменяется выдуманной выдачей.

В другом терминале:

```bash
cd frontend
npm ci
npm run dev
```

Адрес: `http://127.0.0.1:5175`. Vite проксирует `/api` на `http://127.0.0.1:8100`, удаляя
префикс. Другой адрес задаётся переменной `RAG_API_URL` при запуске Vite. При раздаче
`dist/` настройте такой же прокси в веб-сервере. Таймаут прокси — 180 секунд для модельных
операций. Токены находятся только у Python-сервера, в браузер не передаются.

## Сценарий

Описание проверяет Claude. Исправления показываются рядом с вводом. После подтверждения
векторный поиск выдаёт кандидатов, отдельный запрос запускает настоящее переранжирование.
Перед уходом строки подсвечиваются, затем вылетают вправо. Этот ответ сервера анимируется
и после отправки через Enter; системное уменьшение движения сохраняется.

После выбора группы сервис задаёт вопросы для определения точного кода. Можно выбрать
ответ либо написать обычным текстом. Характеристики выбранной позиции приходят из КТРУ:
неизменяемые показываются отдельно, для остальных доступны одиночный или множественный
выбор. Единицы и диапазоны сохраняются в исходных значениях каталога. Свободное дополнение
обрабатывает модель через `/characteristics/text`. Дополнительные параметры проверяет
модель и серверный запрет `noNewFeatures`.

Завершение вызывает `/finish`, после чего результат можно скачать в JSON. Сессии сервера
хранятся в памяти; перезагрузка страницы начинает новый сценарий. Постоянное хранение
и публикация на внешнем портале не реализованы.

## Устройство и проверки

`features/rag-workflow/` — экраны, `entities/rag/` — запросы и состояние. Типы генерируются
из корневого `openapi.json`, экспортируемого настоящим FastAPI-приложением.

```bash
npm run api:generate
npm run verify
npm run test:e2e
```

E2E открывает настоящий локальный интерфейс без подмены API. Smoke-проверки работают
без индекса; полный живой прогон требует векторов и доступа к моделям.
