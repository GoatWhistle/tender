# Визуальная система

Основа: предоставленный макет «Портал поставщиков». Белая шапка со знаком портала,
компактный индикатор четырёх этапов поверх общей рабочей области, диалог на всю ширину без отдельной фоновой панели. Активный этап
красный, основное действие синее. Вложенных карточек и боковой колонки нет.

Токены находятся в `src/shared/styles/tokens/`. Компоненты используют семантические
токены, предусмотрены светлая и тёмная темы. Open Sans подключён локально.

Отправка: квадратная кнопка 44 × 44 со стрелкой вверх. Фокус поля не выделяется при
клике, клавиатурный фокус виден. Контент сообщений ограничен по длине строки, рабочая
область занимает всю доступную ширину. Полоса этапов около 72 px высотой.

Движение: смена содержимого 200 мс, исчезновение нерелевантных позиций 280 мс после 320 мс подсветки,
нажатие 140 мс и отпускание 110 мс. Примитивы в `shared/motion/`; reduced motion и
клавиатурный ввод убирают перемещение. Постоянно вращается только индикатор ожидания.


## Сопровождение и движение

Первый ответ приходит через 5 секунд, ранжирование через 2,5 секунды. В ожидании
показываются пояснения рядом с полем. Уточнение не является сообщением чата: это
редактируемое описание с явным подтверждением. Выбор рекомендованной позиции остаётся
действием пользователя.

| До | После | Причина |
|---|---|---|
| Мгновенная замена списка | Подсветка 320 мс, выход лишних строк 280 мс, перестановка оставшихся 260 мс | Видна связь между кандидатами и итоговым порядком |
| Удаление по исходному номеру | Удаление только идентификаторов, исключённых ответом API | Анимация отражает результат ранжирования |
| Одинаковые варианты | Первый результат подсвечен после перестановки | Понятно, с чего начать выбор |

Проверка движения: одобрено. Меняются только transform и opacity; ease-out задан
токеном; анимации отменяются при смене данных и размонтировании. Для клавиатурного ввода
и reduced motion перестановка происходит без перемещения. Строки доступны для выбора
сразу после получения результата, а не по завершении анимации.


Этапы характеристик и карточки используют текущие токены без новой палитры. Поля
разложены по сетке; замечание и действия находятся под соответствующим полем. Дополнительные
группы раскрываются через общий Disclosure. Итоговый просмотр объединяет иллюстрацию,
позицию КТРУ и параметры; финальное действие сохраняет карточку через API.

Новый активный этап мягко пульсирует два раза по 260 мс, соединительная линия заполняется
через scaleX. Уход кандидатов начинается только после подсветки по фактической разнице
идентификаторов ответа API. Reduced motion и клавиатурный ввод сохраняют мгновенный переход.
