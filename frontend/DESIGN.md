# Визуальная система

Основа — UI-кит «Портал поставщиков» из FigJam-доски
[Portal Postavshikov (catalog)](https://www.figma.com/board/G64ZNZOpvILbIPYx8XVbxO/Portal-Postavshikov--catalog-).
Токены выгружены в `legacy/design/figma/tokens/` и перенесены в `src/shared/styles/tokens/`.

## Сетка и интервалы

Все полосы интерфейса — шапка, этапы, рабочая область, поле ввода — используют один отступ
`--layout-inline`: `max(--layout-gutter, (100% - --layout-max) / 2)`. Поэтому они выровнены по
одной вертикали на любой ширине, а не каждая по-своему.

| Токен | Значение | Откуда |
|---|---|---|
| `--layout-max` | 1320px | сетка Figma 1600: 12 × 88 + 11 × 24 |
| `--layout-gutter` | 24px, с 768px — 32px | поля макета |
| `--grid-columns` | 12, до 768px — 8 | сетки `1280` и `768-8column` |

Шаг интервалов — 4px (`--space-1` … `--space-16`). Вертикальный ритм карточек: внутренний
отступ `--space-8`, промежуток между разделами `--space-8`, между полями `--space-5`.

## Цвет

Из именованных стилей Figma: синий `#264B82`, красный `#DB2B21`, текст `#1A1A1A`, серый
`#7F8792`, линии `#D4DBE6`, фон `#E7EEF7`, зелёный `#0D9B68`, оранжевый `#F67319`, бирюзовый
`#167C85`.

Страница — светло-синяя `#E7EEF7`, содержимое — белые карточки с `--shadow-card`
(`0 2px 20px` от синего, как в макете). Шапка — белая с `Header Shadow` из Figma.

Главное действие — **красное** `#DB2B21`: в ките компонент `btn/red` (128 × 48, заливка
`#db2b21`), рядом `btn/white` для второстепенного. Синий `#264B82` остаётся у ссылок, обводок и
текста второстепенных кнопок — это `--action-text`, отдельный токен от `--action-primary`.
Полоса прогресса в воронке синяя (`--accent-bar`), чтобы её не читали как ошибку.
Высота всех кнопок кита — 48px, совпадает с нашим `--control-size`.

Этапы повторяют `04_Steps & Timer`: пройденный и текущий — красные заливки, будущие —
пунктирная серая обводка.

Серый `#7F8792` на белом даёт контраст 3.63:1 и не проходит WCAG AA для основного текста,
поэтому `--text-muted` — затемнённый оттенок того же тона `#5C6676` (5.81:1). Так же затемнены
зелёный, оранжевый и красный, когда они работают текстом; исходные цвета Figma остались в
палитре для заливок и иконок. Обе темы проверены axe: нарушений нет.

## Типографика

Open Sans 300–800, подключён локально. Размеры — из текстовых стилей Figma: H1 40/52,
H2 30/32, H3 24/32, p4 16/24, p5 14/18, p6 12/16. Межстрочный для заголовков — 1.3: при 1.2
кириллические выносные элементы обрезались.

## Видимость подбора

Три вещи, которые делают процесс подбора наблюдаемым; все три работают на данных, которые API
уже отдаёт, без правок бэкенда.

- **Счётчики у вариантов.** `QuestionOut.counts` — сколько позиций оставит каждый ответ. CLI это
  печатал, интерфейс игнорировал. Теперь у каждого варианта бейдж «позиций: N», и видно цену
  выбора до нажатия.
- **Воронка сужения** (`narrowing.tsx`, `use-narrowing.ts`). `SessionOut.candidates` — это
  оставшиеся конечные позиции, поэтому историю сужения собирает фронт: на каждый новый ключ в
  `answers` пишется шаг «было → стало» с полосой и числом отсеянных. Хук живёт в `workflow.tsx`,
  а не в `Clarification`: та перемонтируется по `key` на каждый вопрос и обнуляла бы историю.
- **Примеры-подсказки.** Четыре описания на стартовом экране, три из них с ошибками разного рода
  (опечатки, метры вместо миллиметров, рост 300 см) — распознавание ошибок показывается одним
  нажатием, без набора текста.

## Движение

Смена содержимого 200 мс, исчезновение нерелевантных позиций 280 мс после 320 мс подсветки,
нажатие 140 мс и отпускание 110 мс, наведение 150 мс. Примитивы в `shared/motion/`; reduced
motion и клавиатурный ввод убирают перемещение. Постоянно вращается только индикатор ожидания.
Каждая длительность `--dur-*` имеет версию для reduced motion — это проверяет тест.

Первый ответ приходит через 5 секунд, ранжирование через 2,5 секунды. В ожидании показываются
пояснения рядом с полем. Уточнение не является сообщением чата: это редактируемое описание с
явным подтверждением. Выбор рекомендованной позиции остаётся действием пользователя.

| До | После | Причина |
|---|---|---|
| Мгновенная замена списка | Подсветка 320 мс, выход лишних строк 280 мс, перестановка оставшихся 260 мс | Видна связь между кандидатами и итоговым порядком |
| Удаление по исходному номеру | Удаление только идентификаторов, исключённых ответом API | Анимация отражает результат ранжирования |
| Одинаковые варианты | Первый результат подсвечен после перестановки | Понятно, с чего начать выбор |

Меняются только transform и opacity; ease-out задан токеном; анимации отменяются при смене
данных и размонтировании. Строки доступны для выбора сразу после получения результата, а не по
завершении анимации.

## Компоненты

Карточка позиции — паттерн «Карточка поставщика» из `09_Cards`: название, под ним мета-строка
колонками «подпись капсом сверху, значение снизу» (там это ИНН/КПП/ОГРН, у нас — код КТРУ и
ОКПД2 с расшифровкой). Компонент `shared/ui/position-meta`, общий для экрана характеристик и
итоговой карточки. До этого ОКПД2 в интерфейсе не показывался вовсе, хотя связь с ним — часть
задачи.

Строка кандидата — сетка «номер · название · код · различия · шаг дальше». Колонки выровнены по верху, код — отдельная колонка, прижатая вправо,
чтобы при появлении колонки различий строка не прыгала. Подсветка при наведении покрывает строку целиком. Причина ранжирования
ограничена двумя строками.

Этапы характеристик и карточки используют те же токены. Поля разложены по сетке; замечание и
действия находятся под соответствующим полем. Обязательность показана бейджем, а не текстом в
колонке подписи. Дополнительные группы раскрываются через общий Disclosure. Итоговый просмотр
объединяет иллюстрацию, позицию КТРУ и параметры; финальное действие сохраняет карточку через API.

Новый активный этап мягко пульсирует два раза по 260 мс, соединительная линия заполняется через
scaleX. Reduced motion и клавиатурный ввод сохраняют мгновенный переход.
