# Словарь данных КТРУ

Смысл полей XML-выгрузки КТРУ, которые читает справочник, и устройство дерева групп. Источник —
«Описание структуры xml с КТРУ» (`data/yandex_disk/КТРУ/`), блоки `nsiKTRUNew/position/data`
и `characteristics/characteristic`.

## Поля

| Поле XML | По описанию структуры | В домене |
| --- | --- | --- |
| `data/isTemplate` | Позиция является укрупнённой (шаблоном) | `Position.is_template` |
| `data/parentPositionInfo/code` | Код родительской позиции КТРУ | `Position.parent` |
| `characteristic/type` | Тип характеристики: 1 — качественная, 2 — количественная | `Characteristic.quantitative` |
| `characteristic/kind` | Вид характеристики: 1 — неизменяемая заказчиком; 2 — изменяемая заказчиком с выбором одного значения; 3 — изменяемая заказчиком, выбор нескольких значений | `Characteristic.kind`: `fixed` / `single` / `multiple` |
| `characteristic/isRequired` | Характеристика обязательна к применению | `Characteristic.required` |
| `characteristic/choiceType` | Тип выбора значений: 1 — единственный, 2 — множественный, 3 — неизменяемый. «Используется в ведении КТРУ. Не используется в применении КТРУ» | только для выгрузок без `kind` |

`Characteristic.multi` — производное от `kind = multiple`. Из `choiceType` его выводить нельзя: в
выгрузках организаторов `choiceType=2` стоит и у характеристик с выбором одного значения
(`kind=2`), и таких большинство. `kind` описание называет обязательным; необязательность — для
обратной совместимости, поэтому при его отсутствии вид берётся из `choiceType`.

## Группа КТРУ

**Группа КТРУ** — шаблон (`isTemplate=true`) или позиция без родителя. Её **конечные позиции** —
потомки по `parentPositionInfo`. Шаблон с потомками конечной позицией не считается; группа без
потомков — в том числе шаблон — сама себе конечная позиция. У позиции группа — она сама, если
позиция — группа, иначе родитель (`Position.group`).

Позиция, чей родитель отсутствует в справочнике или сам не группа, ни в одну группу не входит:
синхронизация возвращает такие позиции в отчёте и пишет их в лог.

API: `GET /api/v1/groups?category=…` — группы категории, `GET /api/v1/groups/{code}` — группа с
конечными позициями, у позиции в `/api/v1/positions/…` — поле `group`.

## Дерево в выгрузках организаторов

Дерево двухуровневое: родитель всегда шаблон, у шаблона нет родителя, у потомков нет своих
потомков. Позиций вне дерева нет.

Конечных позиций на группу:

| Категория | Позиций | Групп | Без потомков (шаблонов) | Медиана | Макс. | 1 поз. | 2–5 поз. | 6–20 поз. | 21+ поз. |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Одежда | 1207 | 212 | 91 (9) | 1 | 112 | 116 | 64 | 21 | 11 |
| Мебель | 402 | 103 | 5 (1) | 2 | 63 | 42 | 56 | 3 | 2 |
| Инструменты | 358 | 117 | 17 (1) | 1 | 18 | 71 | 36 | 10 | 0 |

«1 поз.» — группы без потомков и группы с одним потомком: код у них определён сразу после выбора
группы.

Характеристики по виду, «всего / из них с одним допустимым значением»:

| Категория | Позиции | fixed | single | multiple |
| --- | --- | --- | --- | --- |
| Одежда | шаблоны | 143 / 0 | 425 / 0 | 88 / 0 |
| Одежда | не шаблоны | 2236 / 2236 | 1893 / 125 | 335 / 0 |
| Мебель | шаблоны | 76 / 1 | 691 / 0 | 67 / 0 |
| Мебель | не шаблоны | 445 / 445 | 1444 / 8 | 165 / 0 |
| Инструменты | шаблоны | 46 / 4 | 605 / 3 | 91 / 0 |
| Инструменты | не шаблоны | 185 / 185 | 1369 / 17 | 139 / 0 |

У не-шаблона неизменяемая характеристика всегда имеет одно значение, у шаблона — несколько:
конечные позиции группы различаются неизменяемыми характеристиками.

Обе таблицы печатает `cd backend && uv run python ../evals/catalog/tree_stats.py`.

Smoke-набор `evals/datasets/smoke_v0.json` различает группы по названию, а не по коду: группы с
одинаковым названием в нём сливаются в одну.
