# Зависимости

> Все модели открытые и запускаются локально, без платных API: Qwen3-Embedding-0.6B и Qwen3.5-9B
> под Apache-2.0, OpenJev 4B v5 под MIT. Ревизии весов закреплены в конфигурации; автоматические
> решения принимаются только на закреплённой ревизии. Версии библиотек ниже — из `uv.lock` и
> `package-lock.json` этого коммита.

**Читайте, если** вы проверяете лицензии и воспроизводимость · **Связано:**
[архитектура](architecture.md) · [запуск](running.md)

---

## Какие модели используются?

| Роль | Модель | Ревизия | Лицензия | Где закреплена |
|---|---|---|---|---|
| Поиск групп | `Qwen/Qwen3-Embedding-0.6B`, 1024 измерения | `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3` | Apache-2.0 | `EMBEDDINGS_REVISION`, метаданные векторов в базе |
| Проверки: назначение, мусор, NLI, перечислимые значения | `AlexWortega/openjev`, подкаталог `qwen3.5-4b-nli-v5` | `a20448012c213128955ca0c693e7c943865cab77` | MIT | `DECISION_REVISION`, `VERIFIER_REVISION` |
| Извлечение свободных значений | `Qwen/Qwen3.5-9B` в строгом режиме | `c202236235762e1c871ad0ccb60c8ee5ba337b9a` | Apache-2.0 | `EXTRACTOR_REVISION`, [`services/qwen/profiles/9b`](../services/qwen/profiles/9b/) |
| Извлечение, профиль для карт меньше | `Qwen/Qwen3.5-4B` | `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a` | Apache-2.0 | [`services/qwen/model-manifest.json`](../services/qwen/model-manifest.json) |

Автопринятие работает только с той ревизией, на которой измерен порог: ответ другой ревизии уходит
на подтверждение поставщику. Векторы групп в базе при старте сверяются с ревизией сервиса
эмбеддингов, несовпадение отключает поиск с указанием пересобрать базу. Проприетарные LLM и платные поисковые API не используются, это ограничение ТЗ.
