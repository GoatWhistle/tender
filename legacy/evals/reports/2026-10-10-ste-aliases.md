## Разметка

`evals/datasets/ste_heads_v1.csv`, 313 голов, покрывают 90% строк каждой выгрузки:

| Пометка | Голов | Смысл |
|---|---:|---|
| `group:<код>` | 105 | голова — синоним одной группы |
| `none` | 98 | товара нет в справочнике (свёрла, электроды, оснастка) — кандидаты «вне КТРУ» для #14 |
| `generic` | 102 | голова покрывает несколько групп (стол, куртка, брюки) |
| `skip` | 8 | не решено (3) или синоним снят по замеру (5) |

Группа выбиралась по top-5 поиска, характеристикам и типам изделий позиций КТРУ и по решениям
разметки holdout #14 (сверло — вне КТРУ, болторез и бокорез — кусачки, подстолье — фурнитура).
Головы, где взрослая и детская группы различаются, помечены `generic`, если в примерах заметна
доля детских товаров. Разметка без независимой проверки: строки словаря получают
`reviewed=true`, как требует формат, — проверка их пометок остаётся за ревью PR.

Из 105 `group:` в словарь идут только головы, где гибрид промахивается: размеченная группа не
первая хотя бы в 2 из 3 примеров (у всех голов таблицы по 3 примера). 71 голова уже находится
верно, 2 уже в словаре (с `smoke_v0`), 32 записаны — у каждого источник `ste:<файл>#<строка>`.

## Снятые синонимы

Записано было 38; 6 сняты по замеру и контрольным запросам на новой базе:

| Синоним | Группа | Причина |
|---|---|---|
| шкаф-купе | Шкаф для одежды деревянный | `smoke_v0` «Шкаф-купе металлический …»: top-1 → 2 |
| подстолье | Фурнитура для мебели металлическая | holdout 36669349 «Стол компьютерный … подстолье»: top-1 → 2 |
| головка | Головка сменная торцевая | «Головка шлифовальная цилиндрическая 20x25»: top-1 → 2 |
| маска | Щиток лицевой защитный | общее слово: «Маска медицинская трехслойная» получала щиток первой |
| соединитель | Фурнитура для мебели металлическая | общее слово: «Соединитель для кабеля» получал фурнитуру первой |
| заглушка | Фурнитура для мебели металлическая | общее слово: «Заглушка для трубы 25 мм» получала фурнитуру в top-2 |

Причины записаны в `note` таблицы, пометки сменились на `generic` и `skip` — повторный запуск
`ste_heads.py aliases` их не вернёт. Контрольные запросы на оставшиеся общие слова — «Лазерный
гравер CO2», «Ручка шариковая», «Колесо для тачки», «Крючок рыболовный» — первую группу не
меняют.

## Что изменилось по кейсам

| Набор | Кейс | Ранг правильной группы до → после |
|---|---|---|
| holdout | Плащ ПВХ Hunter КМФ … | вне top-10 → 8 |
| holdout | Гравер ВИХРЬ Г-150 150 Вт | вне top-10 → 4 |
| holdout | Бокорезы AIST 71121105R 140 мм | вне top-10 → 8 |
| holdout | Болторезы ЗУБР 23313-090 900 мм | вне top-10 → 10 |
| `smoke_v0` | кувалда 5 кг с фибергласовой ручкой | top-5 → top-1 |

Пример для слайда (#22): голова «бокорезы» → «Кусачки» (25.73.30.164-00000002). В майнинге 0 из
3 примеров давали «Кусачки» первыми; в holdout «Бокорезы AIST …» правильная группа поднялась
из-за пределов top-10 на 8-е место.

Синоним добавляет вклад RRF одного метода (`1/61`), поэтому редко сам выводит группу на первое
место, если лексика и векторы согласно выбирают другую: «бейсболка» в словаре с `smoke_v0`, но
по 3 примерам из выгрузки первая — «Футболка трикотажная». Чаще синоним поднимает группу в
top-5/top-10. Отсюда рост R@5/R@10 при неизменном R@1 на holdout.

## Как воспроизвести

Из корня репозитория, сервис эмбеддингов на `127.0.0.1:18083`. Таблица и замер «до» — на базе
до синонимов (коммит, где SHA256 артефакта `bfef376…`, и словарь из 6 записей):

```bash
backend/.venv/bin/python evals/ste/ste_heads.py table --embeddings-url http://127.0.0.1:18083/v1 \
  --database <база до>
backend/.venv/bin/python evals/ste/ste_heads.py aliases
cd backend
uv run python build_search_db.py --ktru-dir ../data/yandex_disk/КТРУ/xml \
  --embeddings-url http://127.0.0.1:18083/v1 --output ../artifacts/ktru-search.sqlite3
uv run python ../evals/e2e/run.py --embeddings-url http://127.0.0.1:18083/v1
```

`smoke_v0` — `evals/smoke/bench_search.py --reuse-database` на копии артефакта (см.
`docs/search.md`, «Замер»). `e2e/run.py` строит свою базу из XML и текущего `data/aliases.csv`.
Числа и изменения по кейсам для первого прогона «после» (38 синонимов) и финального (32) — в
соседнем JSON.
