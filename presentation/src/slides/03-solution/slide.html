Описание проходит четыре шага до карточки, и код появляется только на последнем

  1. Описание свободный текст с опечатками и без половины свойств
  2. Группа КТРУ поиск по смыслу и опечаткам, модель проверяет назначение
  3. Сужение позиций правила справочника исключают позиции с причиной
  4. Карточка код 31.01.11.121-00000003 и значения из справочника

Код выбирает не модель. Модели находят кандидатов и проверяют формулировки, код выдаёт правило: осталась ровно одна позиция
