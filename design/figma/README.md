# UI-кит «Портал поставщиков» из Figma

Источник — FigJam-доска [Portal Postavshikov (catalog)](https://www.figma.com/board/G64ZNZOpvILbIPYx8XVbxO/Portal-Postavshikov--catalog-),
последнее изменение 6 ноября 2024. Выгрузка — 10 октября 2026.

## Что где лежит

| Папка | Что внутри | Формат |
| --- | --- | --- |
| `sections/` | 43 раздела доски целиком: цвета, типографика, иконки, кнопки, попапы, шапки, карточки | SVG + PNG @2x (три самых высоких — @1x) |
| `elements/<раздел>/` | 826 элементов первого уровня каждого раздела: слайдер, шапка, попап, карточка | SVG + PNG @2x (без PNG только `fill-607` нулевой ширины) |
| `parts/<раздел>/<элемент>/` | 3 649 вложенных частей элементов (глубина 2–4, от 16px): кнопки, поля, строки таблиц, бейджи | SVG + PNG @2x |
| `components/` | 81 компонент (кнопки, чекбоксы, поля, карточки, иконки), отрисован по первому экземпляру | SVG + PNG @2x |
| `icons/svg/`, `icons/png/` | 379 иконок: раздел `02_Icons` и иконки из остальных разделов | SVG + PNG @4x |
| `images/` | 115 исходных растровых картинок (фото, иллюстрации) в оригинальном разрешении | PNG/JPG |
| `tokens/` | стили и всё реально использованное в макетах | JSON |
| `fonts/` | шрифты макетов с лицензиями | TTF, woff2 |
| `source/file.json` | полное дерево доски без геометрии | JSON |

В git хранятся только `README.md` и `tokens/`. Иконки и шрифты, которые использует фронт, уже
скопированы в `frontend/src/shared/assets/` и `frontend/public/fonts/`. Остальное (рендеры,
иконки, шрифты, картинки и `source/` с деревом на 41 МБ и геометрией на 447 МБ) — около 700 МБ
и 10 тысяч файлов, лежит только локально и закрыто в `.gitignore`.

## Токены

- `tokens/styles.json` — 66 именованных стилей Figma: 25 цветов, 35 текстовых, 2 тени, 4 сетки.
- `colors-used.json`, `typography-used.json`, `effects-used.json`, `radii-used.json`,
  `stroke-weights-used.json` — реальные значения из макетов с частотой.

Основное: шрифт Open Sans (300/400/600/700), синий `#264B82`, красный `#DB2B21`, текст
`#1A1A1A`, серый `#7F8792`, линии `#D4DBE6`, фон `#E7EEF7`, зелёный `#0D9B68`, оранжевый
`#F67319`, бирюзовый `#167C85`. Сетки 1280 и 1600, адаптив 768 на 8 колонок.

## Шрифты

Open Sans (основной, переменный TTF и woff2 с кириллицей), Ubuntu, PT Sans, Cabin, Rubik,
Rounded M+ 1c — все под OFL/UFL, лицензии рядом с файлами. Gotham Pro и Helvetica Neue в макетах
встречаются единично; они платные и не выгружены, в SVG подставлен близкий запасной шрифт.

## Образцы для нашего сценария

- `sections/05-09_pop-ups` — попапы «Добавление характеристик в СТЕ» (таблица «Характеристика |
  Значение | Ед. измерения») и «Сравнение характеристик СТЕ и ценового предложения» (расхождения
  подсвечены ячейками). По ним строим формирование карточки и показ ошибок.
- `sections/01-frame` — спецификация: строки «параметр — значение» и таблица графика поставки.
- `sections/04-05_status-notification-charts` — статусы, уведомления, «Существующие
  характеристики».
- `sections/30-03_buttons-controls` — кнопки, поля, чекбоксы, переключатели, выпадающие списки.
- `sections/06-06_header-and-footers` — шапки и подвалы во всех состояниях и адаптивах.

## Как получено

Растровый рендер Figma API для этого токена упёрся в лимит, поэтому из API взяты только дерево
с геометрией, стили и исходные картинки. SVG собраны локально из путей, заливок, градиентов,
масок, теней и текста (текст — `foreignObject` с подключёнными шрифтами), PNG отрисованы из SVG
в Chromium. 375 иконок из 379 — родной SVG-экспорт Figma, остальные 4 собраны локально. Отличия от Figma возможны в
редких эффектах: фоновое размытие и режимы наложения не воспроизводятся.
