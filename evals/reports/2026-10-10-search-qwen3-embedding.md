# Продуктовый поиск групп КТРУ на smoke_v0: TF-IDF + Qwen3-Embedding + синонимы

**Дата:** 2026-10-10. **Набор:** `evals/datasets/smoke_v0.json`. **Скрипт:**
`evals/search/smoke_search.py`. Метод — `docs/search.md`.

Замер продуктового поиска (`POST /api/v1/search`, тот же сценарий на in-memory хранилищах)
против гибрида из smoke-замера #5 (`2026-10-09-smoke-laya-bge-m3.md`, R@5 = 42/46).

## Итог

| Вариант | R@1 | R@5 | R@10 |
| --- | ---: | ---: | ---: |
| #5: RRF TF-IDF + bge-m3, без синонимов | 30 | 42 | 42 |
| Синонимы с весом 1 в RRF, с инструкцией Qwen | 35 | 41 | 42 |
| **Синонимы с весом 2, с инструкцией Qwen (продукт)** | **37** | **43** | **44** |
| Синонимы с весом 2, без инструкции | 34 | 43 | 43 |

Из 46 кейсов с ответом в КТРУ; кейсы «НЕТ» (2) не считаются.

1. **Порог R@5 ≥ 42/46 выполнен: 43/46.**
2. **Инструкция Qwen к запросу нужна:** R@1 37 против 34, R@10 44 против 43.
3. **Синониму нужен вес 2.** С весом 1 синоним даёт одно слагаемое `1/61`. Группа, которую нашли
   и TF-IDF, и вектор, получает до `2/61`, поэтому «Бейсболка» и «Портмоне» не попадают в top-5
   даже при совпавшем синониме. Вес 2 — наименьший, при котором совпавший синоним ставит свою
   группу выше; вес 3 даёт те же числа.
4. **Числа оптимистичны.** Часть словаря (`source = smoke_v0`) собрана по провалам этого же
   набора: «бейсболка», «портмоне», «картотека». Это набор разработки, а не test.

## Различия с замером #5

- **Группы.** `smoke_v0` размечен названиями групп: их 400 различных. Продукт ищет по кодам —
  432 группы, у части совпадают названия. Попадание засчитывается, если в top-k есть группа с
  названием из `gold`. Группы с одинаковым названием занимают несколько мест top-k, поэтому
  R@k продукта может быть чуть ниже, чем при поиске по названиям.
- **Ранжирование.** В #5 каждый метод ранжировал все 400 групп. В продукте TF-IDF ранжирует
  только группы с ненулевым скором.
- **Нормализация.** Лексический индекс и синонимы видят текст с `ё → е`.

## Задержка

- Индекс: 2 × 432 документа эмбеддингов, 23–27 с.
- Запрос: около 830 мс, из них около 790 мс — один HTTP-вызов эмбеддинга через туннель (замерено
  `curl`). Сам поиск без сети — десятки миллисекунд. Задержку рядом с сервисом не замеряли.

## Промахи top-5 (продукт)

| Текст | Нужно | Top-3 |
| --- | --- | --- |
| Перчатки хозяйственные латексные LAIMA … х/б напыление | Перчатки резиновые общего назначения (кроме медицинских) | Перчатки полимерные; Перчатки швейные …; Перчатки трикотажные … |
| Спец.одежда зимняя Куртка женская МОРОЗКО … | Одежда специальная для защиты от пониженных температур | Куртка зимняя из кожи; Куртка зимняя детская из кожи; … |
| Стол руководителя КОМУС … дуб каньон | Стол письменный / Мебель для офисов … | Стол производственный; Стол демонстрационный; Стол для шахмат |

Все три промаха — тонкое различение внутри семейства групп, а не бытовые названия. Синонимами
они не лечатся; кандидат решения — сужение по характеристикам (#11).
