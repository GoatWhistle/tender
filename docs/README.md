# Документация

> Решение помогает поставщику заполнить карточку товара: по описанию своими словами находит позицию
> КТРУ, сужает группу до одного кода и заполняет характеристики по справочнику, показывая ошибки и
> задавая один вопрос за раз. Код выдаётся только тогда, когда по правилам справочника осталась одна
> позиция. Здесь — как решение устроено, почему именно так, как проверено, где его границы и как
> его запустить.

Обзор — [README проекта](../README.md).
