# План валидации

> На каких данных, какими метриками и с какими порогами проверяется решение. Наборы зафиксированы
> по хешу до прогонов; контрольные выборки не использовались для подбора порогов. Пороги
> автопринятия 0,90 выбраны до проверки и после неё не менялись.

**Читайте, если** вы хотите понять, что именно измерено и почему этим числам можно верить ·
**Связано:** [доказательства](evidence.md) · [ограничения](limitations.md)

## На каких данных проверяется?

| Набор | Объём | Откуда | Для чего |
|---|---|---|---|
| `smoke_v0.json` | 46 описаний с ответом, 400 групп | Сформулирован командой по справочнику | Поиск групп, разработка |
| `dev_v1.json` | 60 сценариев, 3 категории | Сформулирован командой, разметка проверена 60 из 60 | Сквозной прогон, факты, сужение |
| `ste_holdout_v1.csv` | 60 строк, 42 с группой в справочнике | Случайная выборка из выгрузок СТЕ организаторов | Поиск на реальных названиях |
| `enum_holdout_v2.json` | 30 сценариев, 25 пар «поле — значение» | Синтетика, зафиксирована до прогона | Перечислимые значения |
| `errors_ru_v1.json` | 24 случая, 4 класса ошибок | Синтетика по правилам КТРУ | Диагностики |
| `groups/cases.json` | 10 описаний столов | Размечен вручную для регрессии | Проверка назначения |
| `junk_v1.json` | мусор и тексты вне КТРУ | Сформулирован командой | Отсев «вне справочника» |

Все наборы — в [`evals/datasets/`](../evals/datasets/), их описание —
[`evals/datasets/README.md`](../evals/datasets/README.md).

## Что и с каким порогом измеряется?

| Метрика | Определение | Порог | Источник порога | Набор |
|---|---|---|---|---|
| R@5 групп | Правильная группа среди первых пяти результатов поиска | ≥ 42 из 46 | Гибрид TF-IDF и bge-m3 из [smoke-замера](../evals/reports/2026-10-09-smoke-laya-bge-m3.md) | `smoke_v0` |
| R@5 групп на реальных СТЕ | То же на названиях из выгрузок | не задан | Публикуется как есть | `ste_holdout_v1` |
| Точность выданного кода | Доля сессий со статусом «позиция определена», где код совпал с разметкой | ≥ 95 % | [Технический план](Предлагаемое%20решение.md), раздел 15.3 | `dev_v1` |
| Правильные автоматически принятые значения | Доля автоматически принятых перечислимых значений, совпавших с разметкой вместе с привязкой | ≥ 99 % | [Отчёт enum-baseline](../evals/reports/2026-10-10-enum-baseline.md) | `enum_holdout_v2` |
| Ошибочные автовыборы группы | Группа выбрана без вопроса, но не входит в допустимые | не задан | Публикуется как есть | `groups/cases.json` |
| Точность автопринятия фактов | Доля автоматически принятых извлечённых фактов, совпавших с разметкой | не задан | Публикуется как есть | 30 предложений экстрактора |
| Товары, ошибочно отсеянные как мусор | Настоящие описания товаров, получившие «вне КТРУ» | 0 | Критерий выбора порога отсева; набор не независим | `junk_v1` |
| Видеопамять | Суммарная VRAM всех моделей на одной карте | ≤ 40 ГБ | ТЗ, слайд 7 | замер `nvidia-smi` |

## Как устроены прогоны?

Каждый прогон идёт через HTTP API продукта на временной SQLite со схемой из миграций и той же
сборкой сценариев, что в продакшене, с настоящими сервисами моделей. Заглушки в отчётах помечаются.
Отчёт пишет дату, стенд, ревизии моделей и абсолютные числа, а не только проценты.

| Прогон | Команда | Отчёт |
|---|---|---|
| Поиск групп | `backend/.venv/bin/python evals/smoke/bench_search.py --embeddings-url … --database artifacts/ktru-search.sqlite3 --reuse-database` | [`group-search-qwen`](../evals/reports/2026-10-10-group-search-qwen.md) |
| Сквозной | `cd backend && uv run python ../evals/e2e/run.py --embeddings-url …` | [`e2e`](../evals/reports/2026-10-10-e2e.md) |
| Назначение групп | `backend/.venv/bin/python evals/groups/run.py --output var/group-validation.json` | [`group-validation`](../evals/reports/2026-10-10-group-validation.md) |
| Перечислимые значения | `backend/.venv/bin/python evals/enum/run.py --threshold 0.90 --holdout evals/datasets/enum_holdout_v2.json` | [`enum-mapping`](../evals/reports/2026-10-10-enum-mapping.md) |
| Извлечение фактов | `backend/.venv/bin/python evals/extraction/run.py`, затем `score.py` | [`verified-extraction`](../evals/reports/2026-10-10-verified-extraction.md) |
| Диагностики | `cd backend && uv run python ../evals/errors/run.py` | [`diagnostics-fixture`](../evals/reports/2026-10-10-diagnostics-fixture.md) |
| Вне КТРУ | `evals/out_of_scope/measure.py` | [`out-of-scope`](../evals/reports/2026-10-10-out-of-scope.md) |

## Какие правки плана были?

| Дата | Правка | Почему |
|---|---|---|
| 2026-10-09 | Laya Multilingual не используется для выбора группы | Smoke-замер: 34 из 48 и уверенные абсурдные ответы, [отчёт](../evals/reports/2026-10-09-smoke-laya-bge-m3.md) |
| 2026-10-10 | Контрольная выборка перечислимых значений заменена на v2 | v1 была просмотрена при доработке алгоритма и перестала быть независимой |
| 2026-10-10 | Для выбора группы добавлена проверка назначения OpenJev | Сквозной прогон показал R@1 23 из 42 на реальных СТЕ: первая группа поиска часто неверна |
