## Ограничения — слайды 6 и 7

- Linux и веб-интерфейс.
- Без платных поисковых API и внешних API проприетарных LLM.
- Без low-code и no-code.
- Только открытые модели, суммарно не больше 40 ГБ видеопамяти; лёгкие решения в приоритете.
